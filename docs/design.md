# BIO-сайт Романа Сидоренко: «Цепи в бездне»

## Зачем
Личный BIO-сайт. Задача: у человека должно появиться ощущение чужого пространства и что-то близкое к восторгу. Сайт открывается через GitHub Pages.

## Цели
- Полноценное 3D (Three.js): тёмная бездна, туман, частицы, гигантская светящаяся цепь.
- Скролл ведёт камеру вдоль цепи, к звеньям привязаны блоки BIO.
- Внизу цепи висит артефакт: инопланетная шахматная фигура (король из кристалла), вращается от мыши или пальца.
- Нормально работает на телефоне (облегчённый режим на слабых устройствах).

## Не цели
- Никакого бэкенда, сборки и фреймворков: только статика для GitHub Pages.
- Не копия чужого сайта, всё своё.

## Анти-цели
- Тормоза или долгая чёрная загрузка: восторг сразу превращается в раздражение.
- Неразборчивый текст поверх 3D.

## Подходы
1. Настоящее 3D на Three.js + GSAP ScrollTrigger. **Выбран.**
2. Целая чужая планета: эффектнее, но тяжелее, для BIO перебор.
3. 2D-параллакс: быстро работает, но нет ощущения чужого пространства.

## Решения, принятые мной (можно поправить)
- Шахматная фигура в качестве артефакта связывает «чужой мир» с шахматами.
- Рейтинги показаны светящимися счётчиками, которые набегают при появлении.
- Языки программирования показаны как руны, выгравированные на звеньях.
- Three.js и GSAP подключаются через CDN, сайт состоит из одного index.html, CSS и JS.
- Все тексты и рейтинги лежат в одном месте, их легко обновлять.
- Учитывается prefers-reduced-motion.
- Публикация: репозиторий Franixx88.github.io, сайт будет по адресу franixx88.github.io.
